# Brand Sales Intelligence Dashboard

데르뜨·밀도·폴바셋 매출 대시보드의 설치, 데이터 관리 및 화면별 사용 가이드입니다.

## 1. 대시보드 소개

본 대시보드는 데르뜨와 밀도의 매출·판매 데이터를 CSV로 불러와 브랜드별 성과를 확인하는 Streamlit 기반 분석 도구입니다.

- **데르뜨**: 채널, 매출처, 제품 및 MC 카테고리 중심 분석
- **밀도**: 매장 현황, 제품 생명주기, 인기·지속성 및 매장×제품 분석
- **폴바셋**: 밀도와 별개의 매장 매출 Overview

데이터는 데이터 폴더의 CSV를 기준으로 집계되며, DB에는 연결하지 않습니다.

---

## 2. 공통 사용 방법

### 브랜드 선택

왼쪽 사이드바 상단에서 `데르뜨` 또는 `밀도`를 선택합니다. 밀도 브랜드 영역에서는 `밀도 Sales Analytics`와 `폴바셋 Sales Analytics` 드롭다운을 열어 하위 분석 페이지를 선택합니다. 현재 선택된 하위 메뉴는 파란색 버튼과 `현재` 문구로 표시됩니다.

### 조회 기간

화면 우측 상단의 조회 조건에서 기간을 선택합니다.

- 선택 가능 범위는 로딩된 데이터의 최초일과 최종일 사이입니다.
- 데르뜨 조회 기간은 최대 1년입니다.
- 데르뜨 Overview의 일간 모드는 시작일과 종료일을, 월간 모드는 `YYYY년 MM월`을 선택합니다.
- 날짜를 변경하면 KPI, 그래프, 표가 같은 조건으로 다시 계산됩니다.

### 집계 단위

데르뜨 `채널 Sales Overview`에서는 다음 집계 단위를 선택할 수 있습니다.

| 집계 단위 | 그래프 집계 | KPI 비교 기준 |
|---|---|---|
| 일간 | 일별 | 조회 종료일 기준 당일·당월·전월·전년 동월 누계 |
| 월간 | 월별 | 월 매출·당해 누계·전년 동월·전년 누계 비교 |

월간 비교에서 조회 종료일이 말일이면 전월도 말일을 사용합니다.

### 숫자 표시

- 매출 그래프: 백만원 단위, 소수점 첫째 자리
- 수량 그래프: EA 단위
- 숫자: 천 단위 쉼표 표시
- 매출처 상세 실적의 음수 일매출: 빨간 글자와 연한 빨간 배경으로 강조

## 3. 데르뜨 대시보드

### 3.1 채널 Sales Overview

선택 기간의 전체 매출과 판매 현황을 빠르게 확인하는 첫 화면입니다.

#### 상단 KPI

| KPI | 정의 |
|---|---|
| 일매출 | 조회 종료일 하루의 공급가 합계 |
| 당월 누계 | 조회 종료일이 속한 달의 1일부터 종료일까지 |
| 전월 누계 | 전월 1일부터 대응 종료일까지 |
| 전년 동월 누계 | 전년도 같은 달의 1일부터 대응 종료일까지 |

일간 카드의 일매출 증감은 전일과 비교합니다. 전월 누계 및 전년 동월 누계 카드에 표시되는 금액은 각 과거기간 실적이지만, 증감률은 현재 당월 누계가 해당 과거 누계보다 얼마나 증감했는지를 나타냅니다. 카드 Help에서 실제 비교 날짜를 확인할 수 있습니다.

월간 카드의 증감 기준은 월 매출은 전월, 당해 누계는 전년 동기 누계입니다. 전년 동월 매출 카드의 증감은 선택한 당월과 전년 동월을 비교하고, 전년 누계 카드의 증감은 당해 1월~선택월 누계와 전년 1월~동일월 누계를 비교합니다. 두 과거기간 카드의 표시 금액은 전년 실적이지만 증감 방향은 현재 선택기간을 기준으로 하며, 카드 Help에서 비교기간을 확인할 수 있습니다. 해당 비교 데이터가 없으면 `비교 데이터 없음`으로 표시합니다.

#### 매출처 상세 실적

기간별 판매 추이 바로 아래, 채널별 매출 추이 위에는 조회 종료일 기준 채널 요약 피벗이 항상 표시됩니다. `매출처 상세보기`를 열면 기존의 Channel1_1 → Channel1_2 → 매출처 상세 피벗을 확인할 수 있습니다. 매출 금액은 소수점 없이 반올림한 백만원 단위로 표시합니다.

```text
요약: Total sum → Channel1_1

상세보기: Total sum → Channel1_1 → Channel1_2 → 매출처
```

| 열 | 기준 |
|---|---|
| 일매출 | 조회 종료일 하루의 매출 |
| 당월누적 | 조회 종료일이 속한 달의 1일부터 조회 종료일까지 |
| 전월누적 | 전월 1일부터 대응 종료일까지 |
| 전월 누계 증감률 | 당월 누계와 전월 누계 비교 |
| 전년누계 | 전년도 1월 1일부터 대응 종료일까지 |
| 전년동월누적 | 전년도 같은 달의 1일부터 대응 종료일까지 |
| 전년동월 누계 증감률 | 당월 누계와 전년 동월 누계 비교 |

피벗은 짧은 영문 약자를 사용하며 각 컬럼의 Help에서 산식과 실제 비교기간을 확인할 수 있습니다. `MTD`는 당월 누계, `PMTD`는 전월 대응 누계, `YTD`는 당해 누계, `LY MTD`는 전년 동월 누계, `LY YTD`는 전년 누계를 뜻합니다. `MoM %`는 MTD와 PMTD, `YoY %`는 MTD와 LY MTD, `YTD YoY %`는 YTD와 LY YTD의 증감률입니다. 분기 비교값은 없으므로 `QoQ`는 사용하지 않습니다.

- 기본 요약표는 `Channel1_1` 기준으로 집계합니다.
- 접이식 상세보기와 `매출처 실적 CSV 다운로드`는 Channel1_2 및 영업기준 매출처까지 포함합니다.

#### 주요 그래프

- **기간별 판매 추이**: 매출액만 비교하는 선 그래프입니다. 일간은 선택월의 1일부터 실제 말일까지 당월·전월·전년 동월을, 월간은 1~12월 축에서 당해·전년을 비교합니다. 판매가 없는 유효 기간은 0으로 표시하고 아직 도래하지 않은 기간은 선을 연결하지 않습니다.
- **채널별 매출 추이**: 채널 버튼을 선택하면 해당 채널의 기간별 매출을 표시합니다. 일간은 당월·전월·전년 동월, 월간은 당해·전년을 비교합니다.
- **채널별 매출액 TOP 10 제품**: 채널별 상위 제품
- **카테고리별 판매 제품 TOP 10**: 선택한 MC 분류에 속한 제품의 판매수량

채널별 매출 막대의 레이블은 `매출액 (구성비)` 형식이며 Hover에서 매출액, 매출 비중 및 판매수량을 확인할 수 있습니다.

### 3.2 채널 상세 Sales 분석

채널과 영업기준 매출처의 성과를 교차 분석합니다.

- 채널별 일간 매출 흐름
- 매출처 매출 TOP 10
- 매출처별 매출·판매수량 포지션
- 채널별 판매수량 TOP 제품
- 채널별 MC 대분류 매출 비중

매출이 없는 날짜도 그래프에서 0으로 표시됩니다.

### 3.3 제품별 Sales Overview

제품과 MC 카테고리의 매출 기여도를 분석합니다.

- 제품 매출 TOP 10
- 카테고리 매출 구성
- 제품별 매출·판매수량 포지션
- 제품 상세 실적

제품명에 규격값이 포함된 경우 규격 문자열을 제거하고, 끝에 남은 밑줄과 공백을 정리한 이름으로 집계합니다.

## 4. 데르뜨 상세 필터

필터는 위에서 아래로 종속됩니다.

```text
Channel1_1
└─ Channel1_2
   └─ 매출처명(영업기준)
      └─ MC 대분류 → 중분류 → 소분류 → 세분류
```

상위 필터를 변경하면 하위 필터의 선택지는 해당 범위에 맞게 다시 구성되며 기본적으로 전체 선택됩니다.

제품별 Sales Overview에서는 MC 대분류 필터만 제공합니다. 채널 상세 Sales 분석에서는 제품 분류와 집계 단위 필터를 사용하지 않습니다.

## 5. 매출처 인코딩

### 매핑 파일

경로: `data/dertte/매출처_인코딩.csv`

필수 컬럼:

| 컬럼 | 용도 |
|---|---|
| 매출처명(원장기준) | 매출 원장과 조인하는 고유 키 |
| 매출처명(영업기준) | 대시보드에서 집계하는 매출처 |
| Channel1_1 | 1차 채널 구분 |
| Channel1_2 | 2차 채널 구분 |

처리 순서:

1. 매출 원장의 `매출처명`과 매핑 파일의 `매출처명(원장기준)`을 조인합니다.
2. 원장의 기존 `매출처명`과 `유통경로`는 대시보드 집계에서 사용하지 않습니다.
3. 조인된 영업기준 매출처와 두 채널 값을 사용합니다.
4. 원장기준 키가 중복되면 데이터 중복을 방지하기 위해 로딩을 중단합니다.

### 미매핑 처리

매핑되지 않은 원장 행은 삭제하지 않습니다.

```text
매출처: [미매핑] 원장매출처명
Channel1_1: (미매핑)
Channel1_2: (미매핑)
```

사이드바 하단에서 미매핑 매출처 개수를 확인할 수 있습니다. 해결하려면 해당 원장 매출처를 매핑 CSV에 추가합니다.

## 6. 밀도 대시보드

### 밀도 순매출 기준

밀도 원장의 `실매출`은 부가세가 포함된 금액이므로 대시보드에서는 다음 산식으로 순매출을 별도 계산해 사용합니다.

```text
순매출 = 실매출 ÷ 1.1
```

밀도 페이지의 매출 카드·그래프·순위·비중·기간 비교는 모두 순매출 기준입니다. 원본 실매출은 내부 데이터에 그대로 보존합니다. 이 계산은 밀도 매출이 모두 부가가치세 10% 과세 대상이라는 전제입니다.

### 6.1 밀도 Sales Overview

- 순매출과 판매수량
- 운영 매장 및 판매 제품 수
- 폐기수량, 폐기비용, 폐기율 및 폐기 제품 수
- 순매출 1위 매장·제품과 폐기율 1위 매장 인사이트
- 일별 순매출 흐름
- 매장 순매출 TOP 10
- 제품 순매출 TOP 10
- 카테고리 순매출 구성
- 매장×주요 제품 순매출 히트맵

### 6.2 매장 Sales 분석

매장별 순매출 규모와 전체 순매출 비중, 직전 기간 대비 변화를 분석합니다.

- 총순매출과 매장당 평균 순매출
- 최고 매장 순매출
- 직전 기간보다 순매출이 증가한 매장 수
- 매장별 순매출액과 전체 순매출 비중
- 매장별 직전 기간 대비 순매출 증감액
- 선택한 매장의 일별 순매출 흐름 비교
- 선택 매장의 순매출 TOP 10 제품
- 매장별 당기·직전 기간 순매출 상세표

직전 기간은 선택한 조회 기간과 같은 길이로 계산합니다. 예를 들어 8월 1일~8월 31일을 조회하면 7월 1일~7월 31일과 비교합니다. 직전 기간 데이터가 없으면 증가 매장 수와 증감 그래프에 `비교 데이터 없음`을 표시합니다.

### 6.3 제품 Lifecycle 분석

현재 판매 데이터로 제품의 판매 기간과 움직임을 확인합니다.

- 최초 판매일
- 판매 발생일: `판매수량 > 0`인 날짜 수
- 누적 판매수량
- 판매 매장 수
- 제품 폐기율
- 일별 판매수량과 7일 이동평균
- 일별 폐기수량과 폐기율 추이
- 매장별 누적 판매수량
- 제품 폐기 사유별 수량과 금액

안내 문구의 경과기간과 판매 발생일은 구분됩니다. 예를 들어 최초·최종 판매 사이가 31일이더라도 판매수량이 발생한 날이 4일이면 `31일의 기간 중 판매 발생일 4일`로 표시합니다.

#### 7일 이동평균이란?

7일 이동평균은 해당 날짜를 포함한 최근 7일의 판매수량을 평균한 값입니다.

```text
9월 7일의 7일 이동평균
= 9월 1일~9월 7일 판매수량 합계 ÷ 7
```

날짜가 하루 지나면 계산 대상도 하루씩 이동합니다. 조회 시작 후 7일이 지나지 않은 구간은 현재까지 확보된 날짜만 사용해 평균을 계산합니다.

일별 판매수량은 특정 요일, 행사 또는 일시적인 대량 주문으로 크게 흔들릴 수 있습니다. 이동평균선은 이러한 단기 변동을 완화해 판매 흐름이 전반적으로 상승하는지, 유지되는지 또는 감소하는지 확인하는 데 사용합니다. 대시보드에서는 실제 판매수량을 막대, 7일 이동평균을 선으로 표시합니다.

### 6.4 매장 폐기·판매 분석

매장을 하나 선택해 해당 매장의 제품별 판매와 폐기 상태를 진단합니다.

- 매장 매출, 판매수량, 폐기비용 및 폐기율
- 제품별 폐기율 TOP 10
- 제품별 판매수량 TOP 10
- 요일별 일평균 판매수량·폐기수량 및 폐기율
- 선택 제품의 일별 판매수량·폐기수량 및 판매 7일 이동평균
- 매장 폐기 사유별 수량과 금액
- 매장 전체 제품별 매출·판매·폐기 상세표

요일 분석은 조회기간의 모든 날짜를 월~일로 나누며, 해당 매장에 판매나 폐기가 없는 날도 0으로 포함합니다. 요일별 횟수가 서로 달라도 비교할 수 있도록 수량은 `요일별 합계 ÷ 해당 요일 일수`인 일평균으로 표시합니다. 요일별 폐기율은 `요일 폐기수량 ÷ (요일 판매수량 + 요일 폐기수량) × 100`으로 계산합니다. 04 페이지는 매장을 먼저 선택해 제품을 진단하고, 05 페이지는 제품을 먼저 선택해 여러 매장을 비교한다는 차이가 있습니다.

### 6.5 매장 × 제품 운영 분석

선택한 제품이 매장별로 얼마나 판매되는지 비교합니다.

- 취급 매장 수
- 누적 판매수량
- 매장당 평균수량
- 매장별 일평균 판매수량·폐기율 포지션
- 매장별 제품 판매 순위
- 매장별 폐기율 TOP 15

밀도의 세 제품 분석 페이지에서는 MC 대분류가 `기타`인 데이터를 제외합니다.

### 향후 연동 예정

- 입고수량과 재고수량
- 품절 여부
- 제품 출시일과 종료일
- 종합 지속성 점수
- 매장별 확대·유지·축소 운영 권고

## 8. 데이터 파일 관리

### 데르뜨

```text
data/dertte/
├─ 매출 원장 CSV
└─ 매출처_인코딩.csv
```

매출 원장 필수 컬럼:

```text
일자, 매출처명, 품목명, 규격,
MC 대분류, MC 중분류, MC 소분류, MC 세분류,
단가, 수량, 공급가
```

### 밀도·폴바셋

```text
data/mealdo/
├─ 2026_07/
│  ├─ 밀도 매출 CSV
│  ├─ 밀도 폐기 CSV
│  └─ 폴바셋 매출 CSV
├─ 2026_08/
│  └─ 같은 구성의 월별 CSV 3개
├─ 밀도_일별매출_통합.csv
├─ 밀도_폐기데이터_통합.csv
└─ 폴바셋_일별매출_통합.csv
```

월별 원본은 `YYYY_MM` 폴더에 보관합니다. `merge_mealdo_monthly_data.py`가 모든 월 폴더를 읽어 밀도 매출·밀도 폐기·폴바셋 매출을 서로 독립적으로 병합하며, 대시보드는 루트의 통합본 3개만 사용합니다. 특정 월에 일부 유형의 파일이 없어도 다른 유형의 병합에는 영향을 주지 않습니다. 예를 들어 9월 폴바셋 파일이 없으면 폴바셋 통합본은 폴바셋 원본이 존재하는 이전 월까지만 집계됩니다. 같은 유형의 월별 컬럼 구조가 다르거나 `기준일`이 폴더의 연월과 다르면 병합을 중단하고 오류를 표시합니다.

CSV는 UTF-8 with BOM을 권장하며, CP949 파일도 자동으로 읽습니다.

## 9. 데이터 및 대시보드 배포

### CSV만 갱신

`데이터_업데이트.sh`를 Git Bash로 실행합니다.

이 스크립트는 먼저 밀도·폴바셋 월별 파일을 통합 CSV 3개로 병합한 뒤, `data` 폴더 아래의 CSV 변경사항만 커밋하고 현재 브랜치에 Push합니다.

### 코드와 데이터 전체 갱신

`대시보드_업데이트.sh`를 Git Bash로 실행합니다.

이 스크립트는 `.gitignore`에서 제외되지 않은 모든 변경사항을 커밋하고 현재 브랜치에 Push합니다.

### 주의사항

- `secrets.toml`, `.env`, DB 연결 정보는 GitHub에 올리지 않습니다.
- 업로드 전 현재 Git 브랜치를 확인합니다.
- 매출처 인코딩 파일도 CSV이므로 `데이터_업데이트.sh`로 배포됩니다.
- 새 데이터 업로드 후 대시보드가 갱신되지 않으면 앱을 재실행하거나 캐시를 초기화합니다.

## 10. 오류 확인

### 데이터가 표시되지 않는 경우

1. 조회 기간이 데이터 범위 안인지 확인합니다.
2. 상위 필터 변경 후 하위 필터가 선택되어 있는지 확인합니다.
3. CSV 필수 컬럼의 이름과 앞뒤 공백을 확인합니다.
4. 매출처 인코딩 CSV가 존재하는지 확인합니다.

### 매출처 인코딩 오류

- `매출처명(원장기준)`은 중복될 수 없습니다.
- 컬럼명은 정확히 유지해야 합니다.
- 미매핑 행은 합계에서 제외되지 않으며 `(미매핑)` 채널로 표시됩니다.

### 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 11. 운영 권장 절차

1. 새로운 매출 CSV를 기존 파일과 같은 컬럼 구조로 준비합니다.
2. 신규 원장 매출처를 `매출처_인코딩.csv`에 추가합니다.
3. 로컬에서 대시보드를 실행해 총매출과 미매핑 건수를 확인합니다.
4. `데이터_업데이트.sh`를 실행합니다.
5. 배포된 대시보드에서 최종 데이터 날짜와 주요 KPI를 확인합니다.
